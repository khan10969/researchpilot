# 本地数据目录

本目录用于存放 ResearchPilot 的本地论文与处理中间产物。

| 目录 | 用途 | 是否提交 Git |
|---|---|---|
| `documents/` | 已导入的原始 PDF | 否 |
| `incoming/` | 上传过程中的临时文件 | 否 |
| `artifacts/` | Docling 解析结果 | 否 |
| `chunks/` | 文本块和表格块 | 否 |
| `trash/` | 可恢复删除的文献 | 否 |
| `samples/` | 本地演示材料 | PDF 不提交 |

项目仓库不提供第三方论文全文。使用者需要自行导入有权使用的
公开论文、技术报告或实验数据。

文献上传后，系统会完成解析、分块、向量化和 Qdrant 索引。
