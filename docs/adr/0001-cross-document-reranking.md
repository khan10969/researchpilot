# ADR-0001：跨文献问题采用覆盖优先的重排序策略

- 状态：已接受
- 日期：2026-09-03
- 对应基线：v0.4-multi-query-reranker

## 背景

ResearchPilot 使用多查询检索、RRF 融合和 CrossEncoder
对科研文献证据进行二阶段重排序。

初始方案直接保留 CrossEncoder 分数最高的 top-k 证据。
该方案能够减少上下文中的证据数量，但在复杂跨文献问题中
出现了证据覆盖下降。

典型失败案例为 `qa_cross_open_set_metrics_001`。
当 top-k 分别设置为 10、12 和 14 时，包含 ROC、TPR、
FPR、FPR95 以及目标类别数量的细节证据被排除，
导致锚点证据召回率下降到 0.3333，标准事实覆盖率下降到
0.25。

## 原因

CrossEncoder 主要衡量单条文本与问题的整体相关性。

摘要和结论通常与问题整体高度相关，因此容易得到较高分数；
实验设置、表格和具体指标片段虽然包含必要事实，但可能只覆盖
问题的某一个局部维度，因此得分较低。

相关性最高的若干片段，不一定组成信息最完整的证据集合。

## 决策

采用两种重排序策略：

1. 单篇文献或单查询问题：
   对候选证据进行重排序，并截取到请求的 top-k。

2. 跨文献多查询问题：
   对 RRF 和多样性召回产生的完整候选集合进行重排序，
   但暂不根据 CrossEncoder 分数裁剪候选。

CrossEncoder 在跨文献问题中用于调整证据顺序和提供
rerank_score，不再独立决定证据是否被删除。

## 结果

与 v0.3-multi-query 基线相比：

| 指标 | v0.3 | v0.4 |
|---|---:|---:|
| 确定性通过率 | 0.9583 | 0.9583 |
| 锚点证据召回率 | 0.9833 | 0.9833 |
| 语义通过率 | 0.8750 | 0.9167 |
| 标准事实覆盖率 | 0.9459 | 0.9595 |
| 限制说明覆盖率 | 1.0000 | 1.0000 |
| 禁止结论安全率 | 1.0000 | 1.0000 |
| 平均延迟（ms） | 7724.21 | 7507.95 |
| P95延迟（ms） | 14687.58 | 14229.91 |

## 影响

优点：

- 避免复杂问题中的关键证据被相关性模型错误删除；
- 保持文献覆盖、引用有效性和事实覆盖；
- 保留 rerank_score，方便后续分析和界面展示；
- 策略简单，出现异常时容易回退。

代价：

- 跨文献问题的证据数量可能超过请求的 top-k；
- 回答模型需要处理更长的上下文；
- 重排序暂时不能明显降低跨文献请求的 token 消耗。

## 后续工作

后续可以增加“覆盖感知证据选择器”，综合考虑：

- CrossEncoder相关性；
- 每个检索子问题的覆盖；
- 文献覆盖；
- 表格和实验设置覆盖；
- 证据之间的冗余度。

在新的选择器通过完整回归测评前，继续使用当前覆盖优先策略。
